How to use:

Go into dir where main is located and run:
python3 main.py --custom "y" "-sin(x) - b*y"
Where the first eqn is x’ and the second is y’, in this case x’=y and y’ = -sin(x) -by
Parameters other than x and y, get a slider starting at 1, with a range of -5 to 5 to see how they affect the system

Another way is use presets.py and load a preset from there

python3 main.py my_system

python3 main.py --list
Lists all the presets
